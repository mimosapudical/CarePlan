# Release v0.7 — Infrastructure as Code

**Status:** draft  
**Date:** 2026-08-03

## Summary

v0.7 introduces a Terraform-managed AWS practice stack so CarePlan’s cloud topology (API Gateway, Lambdas, SQS, RDS) can be created and destroyed from git instead of the AWS console.

## What’s new

- **IaC module** at `infra/practice/`: reproducible apply/plan/destroy
- **HTTP API** routes: `POST /orders` → create_order Lambda; `GET /orders/{id}` → get_order Lambda
- **Async path:** create_order → SQS → generate_careplan (event source mapping + DLQ)
- **Shared RDS env** wired into Lambda configuration for later real handlers
- **Docs:** architecture, deployment, tradeoffs, engineering notes for Day 15

## What this is not

- Not a production AWS account layout
- Not a permanent staging environment — destroy after exercises
- Lambda handlers in the practice zip may still be stubs; Terraform validates wiring

## How to try

See [deployment.md](../deployment.md). Always run `terraform destroy` when finished testing.
